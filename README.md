# Постоянный мобильный вход erp pilot

Публичная статическая оболочка для `https://dmitriimalahov-gif.github.io/erp-pilot/`.
Она не содержит бизнесданных, учётных записей, паролей, серверного кода или исходного ERP.

`config.json` обновляет локальная служба публикации:

```json
{"version":1,"app_url":"https://example-name.trycloudflare.com","available":true,"updated_at":"2026-11-02T00:00:00Z"}
```

Адрес разрешён только для HTTPS на одном поддомене `trycloudflare.com`, без порта,
учётных данных, пути, query и hash. `available: false` или `app_url: null` отключают вход.
Конфигурация загружается заново при открытии, возврате на страницу и нажатии кнопки входа.

Устанавливаемая оболочка сохраняет постоянный адрес в пределах `/erp-pilot/`.
Кнопка открывает ERP целиком, без iframe. Переход на другой origin может открыть обычное
окно браузера: это определяется мобильной ОС. Иконка постоянного входа остаётся прежней.
Для работы ERP Mac должен оставаться включённым и подключённым к интернету.

Service worker кэширует только фиксированный список статических ресурсов оболочки.
`config.json`, адрес туннеля и бизнесданные не кэшируются. Без сети открывается оболочка
с сообщением о необходимости восстановить интернет; офлайн-работа ERP не заявляется.

RU/RO/EN переключаются локально. Черновики RO/EN подготовлены локальной Ollama
`qwen3.5:9b`, затем проверены и исправлены.
